**Estimated Preparation Time:** 65 minutes

## Task 1 — Arrays and ArrayList (25 minutes)

Watch the following video on Java Arrays and ArrayList:

📹 [Java Arrays - Bro Code](https://www.youtube.com/watch?v=NbYgm0r7u6o)

While watching, refer to **lesson.md Parts 2** and pay attention to:
- How arrays are declared and initialised
- The difference between arrays and ArrayLists
- How to add, remove, and access elements in an ArrayList

**Guiding Questions:**
1. Why can't you resize an array after it's been created?
2. What method do you use to add an element to an ArrayList?
3. What happens when you try to access an index that doesn't exist?

## Task 2 — LinkedList, HashMap and HashSet (25 minutes)

Watch the following video on Java LinkedList, HashMap and HashSet:

- 📹 [Java Collections - LinkedList](https://www.youtube.com/watch?v=5dscMs2hnDI)

- 📹 [Java Collections - HashMap](https://www.youtube.com/watch?v=H62Jfv1DJlU)

- 📹 [Java Collections - HashSet](https://www.youtube.com/watch?v=QvHBHuuddYk)






While watching, refer to **lesson.md Parts 2 and 3** and pay attention to:
- How a LinkedList differs from an ArrayList
- How key-value pairs work in a HashMap
- Why HashSet prevents duplicates

**Guiding Questions:**
1. When would you choose a LinkedList over an ArrayList?
2. What does `.put()` do in a HashMap? What happens if you use the same key twice?
3. What happens when you try to add a duplicate value to a HashSet?

## Task 3 — Big O Notation and Time Complexity (15 minutes)

Watch the following short introduction to Big O Notation:

- 📹 [Big O Notation for Beginners - CS Dojo](https://www.youtube.com/watch?v=D6xkbGLQesk)

While watching, refer to the **Big O table in lesson.md** and pay attention to:
- What O(1), O(n), and O(log n) mean in plain English
- Why HashMap lookups are faster than searching an ArrayList

**Guiding Questions:**
1. If you have 1 million items, how many steps does an O(1) operation take? What about O(n)?
2. Which data structure from this lesson gives you O(1) access — Array, LinkedList, or HashMap?
3. Why does it matter which data structure you choose when data is large?
